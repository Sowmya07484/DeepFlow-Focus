# DeepFlow

DeepFlow is an intelligent focus-enhancement app designed to help you achieve, sustain, and amplify your “flow state.” Built with a modern tech stack, it leverages AI to provide personalized insights and tools for maximum productivity.

## ✨ Features

*   **AI-Powered Weekly Summaries**: Get personalized insights into your focus patterns and progress.
*   **Optimal Focus Time Suggestions**: Discover when you're most productive with AI-driven recommendations.
*   **Intelligent Distraction Filtering**: An AI model helps you decide whether to block or allow notifications based on your current task and priorities.
*   **Personalized Micro-Breaks**: Receive smart suggestions for short breaks to help you recharge and maintain focus.
*   **Focus Timer**: A simple and effective timer to manage your deep work sessions.
*   **Light & Dark Mode**: Switch between themes for your viewing comfort.

## 🛠️ Tech Stack

*   **Programming Language**: TypeScript
*   **Framework**: Next.js (with App Router)
*   **UI Library**: React
*   **Styling**: Tailwind CSS
*   **Component Library**: ShadCN UI
*   **Generative AI**: Google's Genkit
*   **Icons**: Lucide React

## 🚀 Getting Started

To run this project locally:

1.  **Install dependencies:**
    ```bash
    npm install
    ```

2.  **Run the development server:**
    ```bash
    npm run dev
    ```

Open [http://localhost:9002](http://localhost:9002) in your browser to see the result.
